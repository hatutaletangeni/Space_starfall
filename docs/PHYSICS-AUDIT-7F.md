## Scope / interpretation

A browser captures a real Starfall image, not a NASA image. Photo downlink and radio fidelity remain simplified; no unsupported laboratory accuracy or error bar is inferred from a JPEG. Tests labeled **PASS** describe only their recorded coverage. Neither automated Node simulations nor SwiftShader Chrome constitutes actual physical-GPU performance certification.

See `RELEASE-VERIFICATION-7F.md` for actual gate statuses and `reports/PERFORMANCE-7F.md` for separated software-rendered and real-device measurements.
