# STARFALL Update 8E–8K: Engineering model status

**Status: EXPERIMENTAL MODEL PACK, NOT A PLAYABLE RELEASE.** This branch derives from `feature/update-8d-mining-hauling` (not merged to `main`). Nothing in these files is automatically installed as a scene machine, player command or ship component. The Field Manual includes searchable, explicitly labeled entries for 8E–8K.

## Crucial limitations

- The older 8A stock ledger does **not** debit energy. A supplied energy receipt must be generated by a future authenticated in-game power transaction service, never by UI input.
- A schema-valid `assets` object does **not** make a physical controllable rover. The existing Asset Registry, renderer, drive controls and persistence must be wired in and actually tested.
- Mass checks are not sufficient for real-world chemical accuracy. The representative recipes have illustrative yields and must be reviewed for exact atomic balance, energy and emissions before release.
- Model code is intentionally **not referenced from index.html or the offline standalone build**; do not advertise in-game refinery/factory equipment.
- The earlier `feature/update-8e-modular-ship` branch is a different ship-interior feature and should not be confused with this 8E chemical-transformation module.
- Legacy save format and procedural galaxy are unchanged by these unintegrated modules.
